The roadmap is a kanban view of your feedback posts organized into status columns. Use this endpoint to sync your roadmap with external project management tools, trigger column moves from CI/CD pipelines, or build custom roadmap views.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| <span class="badge-method badge-get">GET</span> | `/v1/roadmap` | Get all posts grouped by status column |
| <span class="badge-method badge-patch">PATCH</span> | `/v1/roadmap/posts/:id` | Update a post's status and/or rank |

---

## Get the roadmap

<div class="endpoint-url"><span class="badge-method badge-get">GET</span><code>/v1/roadmap</code></div>

Returns all active (non-merged) posts grouped into status columns, sorted by `rank` ascending within each column, then `createdAt` descending for unranked posts.

### Parameters

| Name | In | Type | Required | Description |
|------|----|------|----------|-------------|
| `status` | query | string | No | Limit to one column: `open` \| `reviewing` \| `planned` \| `in-progress` \| `completed` \| `closed` |

### Request

<Tabs>
  <TabItem label="curl">
    ```bash
    # All columns
    curl https://app.feediyo.com/v1/roadmap \
      -H "Authorization: Bearer YOUR_KEY"

    # Single column
    curl "https://app.feediyo.com/v1/roadmap?status=planned" \
      -H "Authorization: Bearer YOUR_KEY"
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```ts
    // All columns
    const res = await fetch('https://app.feediyo.com/v1/roadmap', {
      headers: { Authorization: 'Bearer YOUR_KEY' },
    });
    const { data: { columns } } = await res.json();

    // Single column
    const res = await fetch('https://app.feediyo.com/v1/roadmap?status=planned', {
      headers: { Authorization: 'Bearer YOUR_KEY' },
    });
    ```
  </TabItem>
</Tabs>

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `id` | string | No | Post ID |
| `title` | string | No | Post title |
| `description` | string | Yes | Post description |
| `status` | string | No | Current column |
| `rank` | number | Yes | Sort position — lower = higher. `null` = unranked (falls to bottom). |
| `voteCount` | integer | No | Total vote count |
| `boardId` | string | No | Board this post belongs to |
| `categoryId` | string | Yes | Assigned category |
| `createdAt` | string | No | ISO 8601 timestamp |
| `updatedAt` | string | No | ISO 8601 timestamp |

## Update a post's status or rank

<div class="endpoint-url"><span class="badge-method badge-patch">PATCH</span><code>/v1/roadmap/posts/:id</code></div>

Move a post to a different column or reorder it within its current column. At least one of `status` or `rank` is required.

<Aside type="tip">
  **Rank arithmetic:** To insert between two posts with `rank: 1.0` and `rank: 2.0`, use `rank: 1.5`. Any float value works — there is no need to renumber existing posts.
</Aside>

### Parameters

| Name | In | Type | Required | Description |
|------|----|------|----------|-------------|
| `id` | path | string | Yes | Post ID |
| `status` | body | string | One of these two | New status column |
| `rank` | body | number \| null | One of these two | Sort position. `null` removes manual ordering. |

### Request

<Tabs>
  <TabItem label="curl">
    ```bash
    curl -X PATCH https://app.feediyo.com/v1/roadmap/posts/post_01xyz789 \
      -H "Authorization: Bearer YOUR_KEY" \
      -H "Content-Type: application/json" \
      -d '{ "status": "in-progress", "rank": 1.0 }'
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```ts
    const res = await fetch('https://app.feediyo.com/v1/roadmap/posts/post_01xyz789', {
      method: 'PATCH',
      headers: {
        Authorization: 'Bearer YOUR_KEY',
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ status: 'in-progress', rank: 1.0 }),
    });
    const { data } = await res.json();
    ```
  </TabItem>
</Tabs>
