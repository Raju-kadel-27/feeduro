Boards group feedback posts by topic — e.g. "Feature Requests", "Bug Reports". They are created and managed in the Feediyo dashboard; the API provides read access.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| <span class="badge-method badge-get">GET</span> | `/v1/boards` | List all boards |
| <span class="badge-method badge-get">GET</span> | `/v1/boards/:id` | Get a single board |

---

## List boards

<div class="endpoint-url"><span class="badge-method badge-get">GET</span><code>/v1/boards</code></div>

Returns all boards for the organization, each with a live post count and embed token.

### Parameters

_No parameters._

### Request

<Tabs>
  <TabItem label="curl">
    ```bash
    curl https://app.feediyo.com/v1/boards \
      -H "Authorization: Bearer YOUR_KEY"
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```ts
    const res = await fetch('https://app.feediyo.com/v1/boards', {
      headers: { Authorization: 'Bearer YOUR_KEY' },
    });
    const { data } = await res.json();
    ```
  </TabItem>
</Tabs>

### Responses

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `id` | string | No | Unique board ID |
| `name` | string | No | Display name shown to users |
| `slug` | string | No | URL-safe identifier |
| `description` | string | Yes | Optional board description |
| `visibility` | string | No | `public` or `private` |
| `isDefault` | boolean | No | Whether this is the default board |
| `embedToken` | string | No | Token for inline embeds — use with `FeediyoBoard` or `data-fdy-embed` |
| `postCount` | integer | No | Count of active (non-merged) posts |
| `createdAt` | string | No | ISO 8601 timestamp |
| `updatedAt` | string | No | ISO 8601 timestamp |

## Using embed tokens

Each board has an `embedToken` that lets you embed it inline — no floating button needed. Use it with the React SDK or the plain HTML snippet:

<Tabs>
  <TabItem label="React">
    ```tsx
    import { FeediyoBoard } from '@feediyo/react';

    // Fetch your boards to get their embedTokens
    const { data: boards } = await fetch('/v1/boards', {
      headers: { Authorization: 'Bearer YOUR_KEY' },
    }).then(r => r.json());

    export default function FeedbackPage() {
      return (
        <FeediyoBoard
          token={boards[0].embedToken}
          style={{ height: 600 }}
        />
      );
    }
    ```
  </TabItem>
  <TabItem label="HTML">
    ```html
    <div
      data-fdy-embed="a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4"
      data-fdy-theme="auto"
      style="height:600px;"
    ></div>
    <script src="https://feediyo.com/sdk/v1/fdy.js" async></script>
    ```
  </TabItem>
</Tabs>
