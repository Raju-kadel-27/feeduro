import { Tabs, TabItem, Aside } from '@astrojs/starlight/components';

Comments are public responses attached to a post. Threaded replies are supported one level deep — a reply cannot have its own replies.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| <span class="badge-method badge-get">GET</span> | `/v1/comments` | List comments on a post |
| <span class="badge-method badge-post">POST</span> | `/v1/comments` | Add a comment |
| <span class="badge-method badge-get">GET</span> | `/v1/comments/:id` | Get a single comment |
| <span class="badge-method badge-delete">DELETE</span> | `/v1/comments/:id` | Delete a comment |

---

## List comments

<div class="endpoint-url"><span class="badge-method badge-get">GET</span><code>/v1/comments</code></div>

Only public comments are returned. Internal (admin-only) comments are excluded.

### Parameters

| Name | In | Type | Required | Description |
|------|----|------|----------|-------------|
| `postId` | query | string | Yes | Post to list comments for |
| `limit` | query | integer | No | Page size — default `25`, max `100` |
| `cursor` | query | string | No | Pagination cursor from previous response |

### Request

<Tabs>
  <TabItem label="curl">
    ```bash
    curl "https://app.feediyo.com/v1/comments?postId=post_01xyz789&limit=25" \
      -H "Authorization: Bearer YOUR_KEY"
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```ts
    const res = await fetch(
      'https://app.feediyo.com/v1/comments?postId=post_01xyz789',
      { headers: { Authorization: 'Bearer YOUR_KEY' } },
    );
    const { data, hasMore, cursor } = await res.json();
    ```
  </TabItem>
</Tabs>

### Responses

          "updatedAt": "2026-02-01T14:00:00.000Z"
        },
        {
          "id": "cmt_01bbb222",
          "postId": "post_01xyz789",
          "parentId": "cmt_01aaa111",
          "body": "Agreed — especially on mobile.",
          "authorId": "up_01www888",
          "authorName": "Bob",
          "createdAt": "2026-02-02T09:00:00.000Z",

  <TabItem label="404 Not Found">

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `id` | string | No | Unique comment ID |
| `postId` | string | No | Post this comment belongs to |
| `parentId` | string | Yes | Parent comment ID for replies. `null` for top-level comments. |
| `body` | string | No | Comment text |
| `authorId` | string | Yes | User profile ID of the author |
| `authorName` | string | Yes | Author's display name |
| `createdAt` | string | No | ISO 8601 timestamp |
| `updatedAt` | string | No | ISO 8601 timestamp |

## Add a comment

<div class="endpoint-url"><span class="badge-method badge-post">POST</span><code>/v1/comments</code></div>

<Aside type="tip">
  Need a `userId`? Call [`POST /v1/users/identify`](/users) with your user's email first.
</Aside>

### Parameters

| Name | In | Type | Required | Description |
|------|----|------|----------|-------------|
| `postId` | body | string | Yes | Post to comment on |
| `userId` | body | string | Yes | Feediyo user profile ID |
| `body` | body | string | Yes | Comment text — max 10,000 characters |
| `parentId` | body | string | No | Reply to a specific comment (one level max) |

### Request

<Tabs>
  <TabItem label="curl">
    ```bash
    curl -X POST https://app.feediyo.com/v1/comments \
      -H "Authorization: Bearer YOUR_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "postId": "post_01xyz789",
        "userId": "up_01zzz999",
        "body": "This would be really useful for power users!"
      }'
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```ts
    const res = await fetch('https://app.feediyo.com/v1/comments', {
      method: 'POST',
      headers: {
        Authorization: 'Bearer YOUR_KEY',
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        postId: 'post_01xyz789',
        userId: 'up_01zzz999',
        body: 'This would be really useful for power users!',
      }),
    });
    const { data } = await res.json();
    ```
  </TabItem>
</Tabs>

### Responses

<Tabs>
  <TabItem label="201 Created">
    ```json
    {
      "data": {
        "id": "cmt_01aaa111",
        "postId": "post_01xyz789",
        "parentId": null,
        "body": "This would be really useful for power users!",
        "authorId": "up_01zzz999",
        "authorName": "Alice",
        "createdAt": "2026-05-30T10:00:00.000Z",
        "updatedAt": "2026-05-30T10:00:00.000Z"
      }
    }
    ```
  </TabItem>
  <TabItem label="404 post_not_found">
    ```json
    { "error": "Post not found", "code": "post_not_found" }
    ```
  </TabItem>
  <TabItem label="404 user_not_found">
    ```json
    { "error": "User not found", "code": "user_not_found" }
    ```
  </TabItem>
  <TabItem label="404 parent_not_found">
    ```json
    { "error": "Parent comment not found", "code": "parent_not_found" }
    ```
  </TabItem>
  <TabItem label="400 cannot_reply_to_reply">
    ```json
    { "error": "Cannot reply to a reply", "code": "cannot_reply_to_reply" }
    ```
  </TabItem>
  <TabItem label="422 Validation Error">
    ```json
    {
      "error": "Validation failed",
      "code": "validation_error",
      "details": { "fieldErrors": { "body": ["Required"] }, "formErrors": [] }
    }
    ```
  </TabItem>
</Tabs>

## Delete a comment

<div class="endpoint-url"><span class="badge-method badge-delete">DELETE</span><code>/v1/comments/:id</code></div>

Deletes the comment **and all its replies**.

### Parameters

| Name | In | Type | Required | Description |
|------|----|------|----------|-------------|
| `id` | path | string | Yes | Comment ID |

### Request

<Tabs>
  <TabItem label="curl">
    ```bash
    curl -X DELETE https://app.feediyo.com/v1/comments/cmt_01aaa111 \
      -H "Authorization: Bearer YOUR_KEY"
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```ts
    await fetch('https://app.feediyo.com/v1/comments/cmt_01aaa111', {
      method: 'DELETE',
      headers: { Authorization: 'Bearer YOUR_KEY' },
    });
    ```
  </TabItem>
</Tabs>

### Responses

<Tabs>
  <TabItem label="200 OK">
    ```json
    { "success": true }
    ```
  </TabItem>
  <TabItem label="404 Not Found">
    ```json
    { "error": "Resource not found", "code": "not_found" }
    ```
  </TabItem>
</Tabs>
